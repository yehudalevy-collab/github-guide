# GitHub Mastery Guide

[![License: MIT](https://img.shields.io/badge/license-MIT-green)](LICENSE)
![Single file](https://img.shields.io/badge/format-single%20HTML%20file-blue)

A complete field guide to Git and GitHub in a single, self-contained HTML file — 12 chapters plus a full command cheat sheet, organized in three difficulty levels from first `git init` to reflog surgery.

**[Read the guide →](https://yehudalevy-collab.github.io/github-guide/)**

Or open [`github-mastery-guide.html`](github-mastery-guide.html) directly in any browser. No build step, no dependencies, works offline.

## What's inside

| Level | Chapters |
|---|---|
| **Basic** | Git vs GitHub: What's the Difference? · Setup & Configuration · The Core Workflow · Working with Branches · Remotes & Forks |
| **Intermediate** | Merging & Conflict Resolution · Pull Requests · Issues, Labels & Projects · `.gitignore`, Stash & Reset |
| **Advanced** | Tags, Releases & GitHub Actions · Rebase, Squash & Clean History · Reflog, Hooks & Power Techniques |

Every chapter is command-first: each concept comes with the exact terminal commands, annotated flag by flag, plus best-practice callouts (opening a good PR, the unbreakable rules of rewriting history, SSH key setup). The final section is a complete cheat sheet you can keep open while you work.

## Who it's for

- Beginners who want one linear path instead of scattered tutorials
- Intermediate users filling gaps (interactive rebase, reflog, hooks)
- Anyone who wants a printable, offline, zero-dependency reference
